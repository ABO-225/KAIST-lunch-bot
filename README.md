# KAIST 메뉴 카카오톡 봇

"아 뭐먹지?" 고민을 제거해주는 HCI 수업의 구원자.

카이스트에는 동측, 서측, 북측 이렇게 3개의 식당이 있다.
우리는 매일 고민을 한다.
어느 식당에서, 어느 메뉴 (샐러드바, 일품 등)를 골라서 먹을 것인지...
일품 메뉴(6500KRW)는 샐러드바(5500KRW)보다 비싼 돈값을 할 것인지...
찾아보기 귀찮았던 메뉴, 이젠 카카오톡으로 클릭 한 번으로 전송하는 프로그램이다.

이 프로그램의 장점은 나물이나 야채 반찬은 과감히 필터링한다는 것.
밥, 국, 고기반찬, 빵 정도만 알려준다. 불필요한 반찬은 생략.

오늘도 우린 학식을 먹는다.
